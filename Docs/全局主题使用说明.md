# 夜航船 · 全局主题使用说明（用户版）

> 适用版本：全局主题一期（自签 / TestFlight 发行版）
> 适用平台：iOS（iPhone / iPad）
> 文档日期：2026-11-28
> 说明：本文只描述**当前版本已经实现**的功能。二期「主题本体 iCloud 同步」代码已就位但默认关闭，本版**未开放**，文中按未开放说明。

---

## 1. 这个功能能做什么

全局主题让你可以改变夜航船**几乎所有界面**的外观——界面颜色、字体、背景、玻璃质感、阅读排版、加载动画等，一次设置全 App 生效。

你能做三件事：

1. **一键套用预设**：六套内置主题，点一下即刻换肤。
2. **自由自定义**：在主题编辑器里逐项调校六个分组，实时预览，满意了再应用。
3. **导入 / 导出主题包**：把喜欢的主题保存为 `.yhthm` 文件备份或在设备间传递。

### 一条重要边界（先说清楚）

**系统启动屏不能改。** iOS 的启动画面是系统接管的静态资源，App 运行时没有接口可以改它。你自定义的「加载画面」指的是 **App 内的**加载状态、转场、骨架屏和首次进入动画，不包括打开 App 那一瞬间的系统启动屏。

**背景始终是静态的。** 网格渐变和光斑不会动——这是为了保证阅读流畅、省电。按压按钮时的轻微反馈动画属于控件交互，不受此限制。

## 2. 怎么进入主题入口

路径：**设置 → 外观与主题 → 主题**

- 在「主题」这一行会显示**当前正在使用的主题名称**。
- 点进去即可打开主题编辑器。
- 旁边的「护眼与外观」是原有功能，负责界面明暗和护眼滤光，两者可以叠加使用、互不影响。

## 3. 套用内置预设

进入主题编辑器后，在「**我的主题**」分组里可以看到六套内置预设，点选即可切换。内置预设无法被真正删除，但你可以基于它「复制为新主题」再改。

| 预设 | 气质 | 适合场景 |
|---|---|---|
| **夜航·原型**（默认） | 冷夜 + 暖灯，深色水面渐变 + 双光斑 | 默认观感，夜间沉浸阅读 |
| **灯下旧卷** | 暖米白纸色，暖调文字 | 暖光下的长篇阅读 |
| **青瓷夜雨** | 冷青雅致，墨青网格渐变 | 偏爱清爽冷色 |
| **霜天晓角** | 高对比浅色，无光斑，加深强调色 | **无障碍优选**：文字与背景对比更强 |
| **墨海金钩** | 深墨配鎏金，暗色渐变 | 深色高质感、低干扰 |
| **竹影护眼** | 浅绿低蓝光渐变 | 长时间阅读，可与护眼层叠加 |

> 小提示：不确定从哪开始时，先用「夜航·原型」或「霜天晓角」作为起点，再复制修改。

## 4. 自定义主题：六个分组

主题编辑器左侧是分组列表，右侧是编辑区，**下方是实时预览**。你调整的任何项目都会立刻反映在预览里，但**此时 App 其他界面不会变**——这就是「草稿隔离」。只有点右上角「**应用**」并确认后，才会全 App 换肤。

编辑器分组如下：

### 4.1 色彩
调整强调色、文字色、辅助色、分隔线、玻璃色调等色板角色，支持浅色 / 深色双档（跟随系统明暗自动切换）和透明度。
- 强调色与「强调色上的文字」会自动配对校验，**正文对比度不足时会黄色标记提示**，并提供「一键修正」。
- 封面色、数据分级色也可在此调整。

### 4.2 字体
- **界面字体 / 标题字体**：可选择系统默认、衬线、圆体、等宽等系统字族，或选择你导入的字体。
- **导入字体**：见第 5 节。
- 字号倍率、字距、段距等在此分组调整。阅读正文的字号 / 行距仍由阅读页的阅读偏好管理，两者会合并生效。

### 4.3 背景
- 类型可选：夜色水面（内置网格）、纯色、线性渐变等。
- **网格渐变（MeshGradient）**：可从内置夜色水面创建 3×3 网格，并调整网格规模（上限 5×5）、锚点与每个网格点的颜色。
- **光斑**：可开关、调数量（最多 3 个）、颜色、半径和位置。全部为静态，无动画。
- 也可使用你导入的图片作为背景（图片会在导入时自动降采样，最长边 2048）。

### 4.4 玻璃与组件
调整圆角大小、分隔线粗细、玻璃质感强度、按压反馈等控件观感。

### 4.5 阅读排版
调整阅读相关配色（正文背景 / 文字 / 次要文字 / 强调色）与浅深模式。阅读页默认跟随全局主题；如果你在阅读页单独选过预设背景或字体，那部分会保持你的单独设置，可在阅读页「恢复跟随全局」。

### 4.6 加载与状态
- 加载样式：系统转圈 / 品牌标记 / 图片 / 骨架屏。
- 转场：灵动 / 克制 / 关闭。
- **尊重「减弱动效」**默认开启：系统开了减弱动效时，动画自动降级为静态。首次进入动画也遵守这一设置。

### 4.7 我的主题（主题库）
当前主题改名、复制为新主题、删除当前主题。删除后 5 秒内可撤销。含字体资产的主题删除时，字体会一并删除，请注意提示。

## 5. 导入字体（含版权须知）

> **App 不内置任何第三方字体。** 系统字族之外的字体，只能由你自己从「文件」App 导入，且需要你确认拥有合法使用授权。

操作：主题编辑器 →「字体」分组 →「导入字体文件」→ 在文件选择器里选 `.ttf` / `.otf` 文件 → 在「字体版权确认」弹窗中确认 → 完成后该字体会出现在字族选项里。

要点：
- 只接受 `.ttf` / `.otf`，且会校验文件头（字体真实格式），单文件不超过 10MB。
- 导入前会**先弹版权确认**，确认后才落盘和注册；取消则不导入。
- 字体只在 App 进程内临时注册，**不会写入系统字体库，也不影响其他 App**；每次启动会重新注册。
- 如果字体损坏或注册失败，会自动回退到系统字体，不会让界面变成空白。
- 从 `.yhthm` 主题包里带进来的字体，同样是「你自有字体的迁移」，**会单独再次要求版权确认**，不能因为之前确认过就跳过。

**版权责任在使用者**：请确保你有权使用该字体并有权在主题包中分发它。请不要导入、分发来源不明或授权不明的商业字体。

## 6. 导入 / 导出主题包（`.yhthm`）

主题编辑器支持把主题连同它用到的图片、字体一起打包成 `.yhthm` 文件（本质是一个 ZIP），用于备份或在设备之间传递。主题包为**纯数据**，不含任何可执行脚本。

- **导出**：会生成 `manifest.json`（清单 + 每个资产的校验值）、`theme.json`（主题本体）和 `assets/`（资产）三部分。
- **导入**：会先做一整套安全检查——ZIP 格式、整包不超过 50MB、单资产不超过 10MB、解压总量不超过 100MB、路径不允许 `../` 穿越、不允许重复条目 / 加密 / 符号链接、逐资产校验和比对、清单版本不能比 App 更新。检查不过会明确报错，不会使 App 崩溃。
- **ID 冲突**：如果导入的主题和本机已有主题 ID 相同，会分配新 ID 保留两份，**不会静默覆盖**你现有的主题。
- **版本较新**：如果主题包来自更新的 App 版本，只能预览、不能导入。

> 包内含字体时，导入同样会独立弹出版权确认，请按第 5 节的版权须知处理。

## 7. 备份与 iCloud 说明

- **备份**：在「设置 → 备份」中创建备份时，只要勾选了「**阅读偏好**」（`preferences`）范围，主题就会一起备份（含主题本体和资产，资产总量上限约 15MB）。恢复时按「先装资产 → 替换主题库 → 设置当前主题」的顺序还原。若资产超过上限，备份只保留主题本体，自定义资产需要你用 `.yhthm` 手动导出。
- **iCloud（一期，已实现）**：目前只同步**当前选中的主题 ID**（`activeThemeID`）。如果同步过来的主题在本机不存在（例如指向一台设备上的自定义主题），App 会**回退到内置默认主题并提示你**导入 `.yhthm`——不会静默变样。
- **iCloud（二期，未开放）**：主题本体（自定义主题的完整内容和资产）的跨设备同步代码已写好，但**默认关闭、尚未接入开关**，当前版本**不能使用**。请不要把它当作已开放功能。

## 8. 无障碍说明

- **高对比预设**：「霜天晓角」是为无障碍准备的高对比预设，强调色加深至约 4.5:1、纯色背景无光斑。
- **对比度护栏**：自定义色彩时，正文对比度不足会给出黄色提示与「一键修正」，避免配出「字看不见」的组合。
- **动态字体（Dynamic Type）**：主题只提供基准字号倍率，不覆盖系统的字体缩放；系统字体放大时正文会跟着放大。
- **减弱动效（Reduce Motion）**：系统开启后，加载动画、转场和首次进入动画自动降级为静态。
- **触控尺寸**：主要交互控件的触控区域不小于 44pt。
- **色盲友好**：数据分级色提供数值等替代呈现，不单纯依赖颜色区分。

> 建议：如果看不清某些文字，优先切换到「霜天晓角」，或在「色彩」分组里用「一键修正」，再配合系统「辅助功能」里的显示与文字大小设置。

## 9. 常见问题（FAQ）

**Q：我在编辑器里调了半天，App 界面怎么没变？**
A：编辑器里是**草稿预览**，只有点右上角「应用」并确认后才会全 App 生效。这是为了防止误操作。点「取消」则丢弃所有改动。

**Q：切换主题后阅读页字体 / 背景没跟着变？**
A：如果你之前在阅读页单独设置过背景预设或字体，那部分会保持你的单独设置。去阅读设置里选择「恢复跟随全局」即可。

**Q：为什么系统启动画面没变？**
A：系统启动屏由 iOS 接管，运行时无法自定义，这是平台限制。可自定义的是 App 内的加载态与转场。

**Q：导入的字体在列表里找不到 / 显示成系统字？**
A：可能是文件格式不对、已损坏或注册失败，会自动回退系统字。请确认文件是合法 `.ttf` / `.otf` 且未超过 10MB。

**Q：换主题会不会卡、掉帧？**
A：背景都是静态的且做了解析缓存，正常不应掉帧。如果在低端设备上遇到卡顿，建议减少光斑数量、把网格降到 3×3、或改用纯色 / 线性渐变背景。

**Q：主题会在我的几台设备之间同步吗？**
A：一期只同步「当前选中的主题 ID」。自定义主题的完整内容跨设备同步（二期）当前版本**尚未开放**，请用 `.yhthm` 手动导出导入。

**Q：删除了带字体的主题，字体还在吗？**
A：删除主题时其字体资产会一并删除（删除前有提示，5 秒内可撤销）。如仍需该字体，请先导出 `.yhthm` 备份。

**Q：主题包导入失败并提示版本较新 / 校验失败？**
A：说明该包来自更新的 App 版本或文件已损坏 / 被篡改。请使用与当前 App 版本匹配的包，或从原始设备重新导出。
